# 1. 워드 임베딩

## 1-1. 원-핫 인코딩

```원 핫 인코딩이란?```
- 규칙 기반 혹은 통계적 자연어처리 연구 대다수는 단어를 원자적(쪼갤 수 없는)기호로 취급
  예:hotel, conference, walk 같은 단어들
- 벡터 공간 관점에서 보면, 이는 한 원소만 1이고 나머지는 모두 0인 벡터를 의미
- 차원 수(= 단어 사전 크기)는 대략 다음과 같다:
    - 음성 데이터(2만) - Penn Treebank(PTB)코퍼스(5만) - big vocab(50만) - Google 1T(1300만)
- 이를 원-핫(one-hot) 표현이라고 부르고, 단어를 원-핫 표현으로 바꾸는 과정을 원-핫 인코딩(one-hot encoding)이라 한다

```원 핫 인코딩의 문제점```

1. 차원의 저주
   - 고차원의 희소 벡터를 다루기 위해선 많은 메모리 필요
   - 차원이 커질수록 데이터가 점점 더 희소(sparse)해져 활용 어려움
   
2. 의미적 정보 부족
검색 쿼리 벡터와 대상이 되는 문서 벡터들이 서로 직교하게 되어, 원-핫 벡터로는 유사도 측정 x
(배터리 사이즈) != (배터리 용량)
(갤럭시 핸드폰) != (갤럭시 스마트폰)
같은 의미를 가진 단어임에도 다른 단어로 이해함(의미적 정보 부족)

## 1-2. 워드 임베딩

- 단어를 주변 단어로 표현(문맥)
- 현대 통계적 자연어처리에서 가장 성공적인 아이디어 중 하나

```워드 임베딩이란?```
- 단어를 단어들 사이 의미적 관계를 포착할 수 있는 밀집되고 연속적/분산적 벡터로 표현하는 방법
- 두 단어의 벡터가 공간상 서로 가깝게 위치하여, 의미적 유사성 반영 가능

```Word2Vec - 대표적인 워드 임베딩 기법```
워드 임베딩의 시초격 기법 - 단어의 표현을 간단한 인공 신경망(아마 퍼셉트론?) 이용해 학습

```Word2Vec의 두 가지 알고리즘```
1. Skip-grams (SG) 방식
   - 중심 단어를 통해 주변 단어들을 예측
   - 단어의 위치(앞/뒤)에 크게 구애 받지 않음
2. Continuous Bag of Words (CBOW) 방식
   - 주변 단어들을 통해 중심 단어 예측
   - 문맥 단어 집합으로 중심 단어를 맞춘다

```Skip-grams(SG)```
- 윈도우 크기 = 중심 단어 주변 몇 개 단어를 문맥으로 볼 것인가?
  중심 단어 위치에서 얼마나 떨어진 단어를 볼지 확인

```Continuous Bag of Words (CBOW)```
- 목표: 주변 단어 집합이 주어졌을 때 그 문맥과 함께 등장할 수 있는 단일 단어 예측

```Skip-Gram vs CBOW```

- Skip-Gram
  - 적은 데이터에도 잘 동작
  - 희귀 단어나 구 표현에 강함
  - 한계: 학습 속도 느림
- CBOW
  - 학습 속도 빠름
  - 자주 나오는 단어에 강함
  - 한계: 희귀 표현에 약함

 # 2. 순차적 데이터
 ``` 순차적 데이터란?```
 - 데이터가 입력되는 순서와 이 순서를 통해 입력되는 데이터들 사이 관계가 중요한 데이터
(오디오, 텍스트, 비디오)

```순차적 데이터의 특징```
1. 순서가 중요
   - 데이터의 순서가 바뀌면 의미가 달라진다
2. 장기 의존성
   - 멀리 떨어진 과거 정보가 현재/미래 영향을 준다
3. 가변 길이
   - 길이 일정치 않고 단어 수 제각각이다

**순차적 데이터 처리를 위해서는 일반적 모델들로는 불가 RNN, LSTM, Transformer 등 Sequential Models 사용**

# 3.RNN
- 전통적 인공신경망(MLP, CNN)들은 고정된 길이 입력을 받아 가변 길이 데이터를 처리하기에 부적합
  
```RNN이란?```
- 가변 길이 입력을 받고, 이전 입력을 기억하는 순차적 데이터 처리에 적합한 아키텍처(many to many)
- 전통적 신경망과 달리 이전 시점의 정보를 담는 hidden state를 가지고 있음
- 입력 시퀀스 벡터 x를 처리할 때, 각 시점마다 recurrence 수식을 적용해 hidden state 업데이트
  
ht = fw(ht-1, xt) => 
새로운 hidden state = 처리함수(이전 hidden state, 입력 벡터)

```RNN의 한계 기울기 소실```
- 기울기 소실
  - 딥러닝에서 역전파 시 앞쪽 층의 기울기가 0에 가까워져 장기 의존성 학습이 어려워지는 현상

1. 역전파 과정에서 작은 값들이 계속 곱해진다
2. 과거 시점에서 온 오차 신호는 갈수록 더 작을 기울기를 가진다
3. 결국 파라미터들이 장기 의존성 학습 못 하고 단기 의존성만 포착한다.
