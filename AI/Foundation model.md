1-1. 파운데이션 모델
```AI 모델```
- 입출력 연결 + 데이터로 학습 + **학습 때 보지 못한 데이터에도 의무적으로 작동**하는 함수

현실적인 기계학습 모델
- 학습 = AI모델에 데이터를 패턴화 해 압축
- 이 과정에서 유사성을 파악하고 패턴을 익히며 새로운 데이터에 대한 일반화 능력생 형성

파운데이션 모델
- 대규모 데이터를 폭넓게 학습해 다양한 문제에 빠르게 적응할 수 있는 **범용 대형 AI 모델**
- 공학 / 과학적으로 엄밀한 특성을 갖지는 않음(정의의 주관성) => 프론티어 모델

기존 딥러닝 개발 패러다임: 기본적인 것들부터 배워야함(노베이스 쌩신입)
파운데이션 모델 패러다임: 거대모델 + 대규모 데이터 학습 기반(중고 신입)

특징
1. 대규모
   - 태스크에 상관없이 비슷한 패턴 등장
   - 주로 비지도 학습 으로 훈련된 모델들도 많이 등장(쉬운 데이터 수집, 대규모 학습)
2. 적응성
   - 높은 파인 튜닝 성능(믿고 쓸 수 있는 모델)
3. 범용성
   - 다양한 작업, 한정되지 않는 출력 지원(예시: 물체 판별 기존에 20개 종류 구분이 만 개 이상으로 확대)
